# Prompts

Articles the corpus is asking for. Each one states what it would argue and why it can be written now, so a draft can start from a position rather than a topic.

A prompt earns a file when the wiki turns something up that has nowhere to go: a mechanism with more evidence than any single piece uses, a question arrived at repeatedly, an argument that got 900 words and needed 3,000.

**Not a content calendar.** Nothing here is owed. A prompt that sits untouched for six months was probably never an article, and deleting it costs nothing.

**Each prompt says four things.** The claim, in one sentence a reader could disagree with. The evidence already in hand. What is missing. And what would make the piece fail, which is usually the most useful line in the file.

Written blunt, like the rest of the wiki. Prose written to essay standard turns a prompt into a first draft, and then the draft never gets written.
